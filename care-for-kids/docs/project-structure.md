# Project structure

| Path | Purpose |
| --- | --- |
| `dist/index.html` | Page markup and content |
| `dist/styles.css` | Styling and responsive layouts |
| `dist/reading.jpg` | Hero photograph |
| `check.mjs` | Local asset and anchor checks |
| `utils.mjs` | Date and clamp helpers |
| `broken-math.mjs` | Average and even-number helpers |
| `broken-fetch.js` | Configuration and user-fetching helpers |
| `docs/` | Maintenance guides |

The HTML does not load the root JavaScript helpers. Website files are edited directly in `dist`.
