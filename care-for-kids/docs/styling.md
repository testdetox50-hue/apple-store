# Styling

`dist/styles.css` defines shared colors in `:root`: `--ink`, `--paper`, `--yellow`, `--pink`, and `--green`. Some components use literal colors, so preview the full page after changing these variables.

Body text uses DM Sans, headings use Manrope, and selected accents use Georgia.

Responsive rules use 950px and 680px breakpoints, with an additional rule for screens at least 1320px wide. Review narrow and wide layouts after editing spacing.

A reduced-motion media query disables smooth scrolling and button transitions.
