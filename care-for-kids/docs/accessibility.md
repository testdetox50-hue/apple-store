# Accessibility review

Use these checks after editing; this guide is not an accessibility certification.

- Navigate links and FAQ summaries using the keyboard and check visible focus.
- Open and close FAQ entries with the keyboard.
- Keep meaningful image alternative text and hide decorative symbols from assistive technology.
- Preserve heading associations in `aria-labelledby` attributes.
- Review contrast after changing colors.
- Review enlarged text and narrow layouts.
- Check the page with reduced motion enabled.

The asset checker does not evaluate these behaviors.
