# Asset management

The hero photograph is `dist/reading.jpg`. Attribution appears in the page and project README.

When replacing it, update alternative text, dimensions, and attribution as appropriate. Preview the crop because the image uses `object-fit: cover`.

Store local website assets inside `dist`, referencing them relative to `dist/index.html`. Match filename capitalization for case-sensitive hosts.

The favicon is an inline SVG data URL in the document head. Fonts load externally through the stylesheet.
