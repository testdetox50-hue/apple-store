# Content editing

Edit copy in `dist/index.html` and save as UTF-8. Preserve the heading hierarchy: one `h1`, section titles using `h2`, and card titles using `h3`.

Care cards use `article.care-card`. Play ideas use articles inside `.activities`. FAQ entries use native `details` elements with a `summary` question.

Keep copy concise and supportive. Preview longer text on a narrow screen to catch overflow. Update the document title and description if the site's purpose changes.
