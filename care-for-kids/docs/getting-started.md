# Getting started

Open `dist/index.html` in a browser. No installation or build step is required.

Edit `dist/index.html` for content and `dist/styles.css` for presentation, then refresh the browser.

With Node.js installed, run `node check.mjs` from the `care-for-kids` directory to verify local assets and navigation targets.

Google Fonts requires internet access; fallback fonts are supplied in the CSS.
